# Random Timetable Frontend (Ocean Professional)

A lightweight React frontend to generate random school timetables. Features a modern, minimalist UI with blue (#2563EB) and amber (#F59E0B) accents, rounded corners, soft shadows, and subtle gradients.

## Features
- Student inputs for Grade/Class, Days per week, Periods per day, and Subjects
- Random timetable generation with simple constraints (no immediate repetition in a day)
- Ocean Professional theme with light/dark toggle
- Clean, extendable component structure in a single-file app for simplicity

## Scripts
- `npm start` — Start development server
- `npm test` — Run tests
- `npm run build` — Create production build

## Notes
All configuration is local; no environment variables are required. The app is framework-only (React + CSS), with no UI libraries to keep it minimal and fast.
